# PDF 摄取与检索评估

对比 MarkItDown 转换与采用 PDF 文本层逐页提取的摄取流程。100 份 PDF 中有 90 份公开论文，另有 10 份项目样例及演示资料；其中仅论文的文本提取方式发生变化。

- 固定 200 道题、同一套向量模型、切块参数和检索设置，两个版本均跑两轮。198 道有答案题参与 Hit@5，测试集包含 181 道采用 QASPER 证据标注的题。
- 两路各取 10 条，RRF 常数为 60，取前五条判断是否命中任意相关片段。分块为 450 字符，重叠 100 字符。
- 每轮 RRF 命中题数从 17/198 变为 32/198，即 Hit@5 从 **8.59%** 提升至 **16.16%**。无法映射到入库片段的证据从 104 题降到 0 题，检索 P95 从约 1.08 秒增至 1.13 秒。

这个对照衡量的是 PDF 摄取变化对同一检索链路的影响。样本以公开论文问答为主。生成评估和检索命中分别计算。
